# Journey to English — نسخه واقعی قابل استقرار

این پروژه نسخه سروری واقعی آکادمی Journey to English است؛ نه نسخه localStorage. دیتابیس PostgreSQL دارد و فایل ویدئو داخل volume خصوصی نگهداری می‌شود.

## امکانات
- طراحی راست‌به‌چپ و نزدیک به طرح اولیه Journey to English
- پنل مدیر با ورود امن و Cookie HttpOnly
- فقط مدیر می‌تواند دانش‌آموز، دوره، درس، بخش و ویدئو اضافه کند
- آپلود و جایگزینی ویدئو از داخل پنل مدیر
- فعال یا قفل کردن دوره برای هر دانش‌آموز
- پنل دانش‌آموز با دسترسی اختصاصی
- پخش ویدئو از مسیر خصوصی با URL امضاشده و کوتاه‌عمر
- فایل ویدئو داخل `public` نیست و لینک دائمی فایل به دانش‌آموز داده نمی‌شود
- PostgreSQL + Prisma
- Docker Compose آماده استقرار

## اجرای واقعی روی سرور
1. Docker و Docker Compose روی سرور نصب باشد.
2. `.env.example` را به `.env` تبدیل کن و رمزهای قوی بگذار.
3. اجرا: `docker compose up -d --build`
4. سایت روی پورت 3000 بالا می‌آید.
5. برای دامنه واقعی، یک Reverse Proxy مثل Nginx/Caddy و HTTPS روی سرور تنظیم کن.

## ورود مدیر
نام کاربری از `ADMIN_USERNAME` و رمز از `SEED_ADMIN_PASSWORD` ساخته می‌شود.

## ورود دانش‌آموز
دانش‌آموز شماره موبایل ثبت‌شده را وارد می‌کند، کد یک‌بارمصرف دریافت می‌کند و سپس وارد پنل خودش می‌شود. شماره‌ها به‌صورت خودکار یکسان‌سازی می‌شوند؛ بنابراین 0912، ۰۹۱۲ و +98 همدیگر را درست تشخیص می‌دهند.

برای پیامک واقعی، در `.env` مقدار `SMS_PROVIDER=kavenegar` و `KAVENEGAR_API_KEY` و `KAVENEGAR_TEMPLATE` را تنظیم کن. قالب پیامک در کاوه‌نگار باید یک توکن برای کد داشته باشد. در حالت توسعه، کد OTP در پاسخ API نمایش داده می‌شود.

## آپلود ویدئو
از پنل مدیر، بعد از ساخت دوره ← درس ← بخش، روی «آپلود / جایگزینی» بزن. فایل ویدئو روی volume خصوصی سرور ذخیره می‌شود و از مسیر عمومی سایت قابل دسترسی مستقیم نیست.

## روند استفاده تو
مدیر ← ساخت دانش‌آموز ← ساخت دوره ← ساخت درس ← ساخت بخش ← آپلود ویدئو ← فعال‌کردن دوره برای دانش‌آموز.

## نکته مهم درباره دانلود
هیچ مرورگری نمی‌تواند ضبط صفحه یا استخراج داده را 100٪ غیرممکن کند. این نسخه لینک عمومی و دائمی ویدئو نمی‌دهد، دسترسی را با حساب و دوره کنترل می‌کند و URL پخش را کوتاه‌عمر و امضاشده می‌سازد.
